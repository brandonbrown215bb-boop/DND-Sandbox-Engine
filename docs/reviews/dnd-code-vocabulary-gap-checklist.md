# D&D code-vocabulary gap checklist

This owns broad capability scope, source examples and remaining requirements.
The [slice registry](../planning/vocabulary-slices.md) owns slice status and
verified boundaries; the [roadmap](../../roadmap.md) chooses work. Historical
research informs these requirements but isn't current gameplay certification.

The 31 families are navigation, not completion boxes. V-series rows distinguish
capabilities that need separate behavior. The target remains one shared 2024
runtime under ADR-0018, with SRD 5.2.1 governing the staged core-12 milestone.

**Status terms:** *shared/data-expressible* means the behavior is available as ordinary shared data within the described boundary; *partial* means some reusable execution exists but the listed generality or behavior is absent; *hard-coded only* means behavior exists through identity-specific/native policy; *missing* means no adequate current operation/state path was identified; *uncertain* means static evidence does not establish support. Discovery did not probe uncertain items. The slice registry retains later production evidence; this reconciliation adds no gameplay checks.

## Concrete vocabulary checklist

These are building blocks, not 99 new modules or a demand to implement every
example. Each box covers the boundary stated in its row. Different damage types,
die sizes, distances and reset counts are parameters unless they change execution
semantics. Examples identify local source descriptions, not certified gameplay.

All 99 parent boxes remain open where their full boundary is unfinished. The
checked VS items above record accepted smaller boundaries from retained logs.
**Partial** includes those proved subsets as well as older paths established only
by source inspection; only the cited subset is verified. **Uncertain** means a suitable generic path
has not been established; a likely hook is a place to start, not proof of support.
**Missing** is used only for the previously documented absent general capability.
Dependencies are prerequisite vocabulary, not mandatory up-front scaffolding.
Source keys such as C-Rogue and I are linked in the discovery scope below.
