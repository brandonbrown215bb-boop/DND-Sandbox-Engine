# ADR-0002: Crown-band Wild Shape proposal withdrawn

Date: 2026-08-10
Status: Withdrawn, 2026-10-09; never accepted
Replaced direction: [ADR-0004](0004-staged-2024-rules-and-save-boundary.md),
[ADR-0018](0018-shared-data-driven-rules-runtime.md)

The original proposal used a Wolf-only roster, form HP absorption and encounter
reversion from an older bounded rules approach. ADR-0004 explicitly rejected
it as authorization for 2024 Wild Shape. Those mechanics and its human-review
questions no longer guide implementation or block development.

Future form work needs source-verified 2024 semantics, data-defined projections
and production checks for identity, equipment, costs, movement, reversion and
durable state. Preserve existing supported behavior while replacing it; this
withdrawal neither disables code nor certifies current forms. Read the
[Druid behavior snapshot](../mechanics/druid-2024.md) and current source for
migration input. Curated reversible forms remain open work in the
[checkpoint](../operations/current.md).
