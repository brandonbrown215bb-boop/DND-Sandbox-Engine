# Original mixed-edition reference inputs

These original files contain multiple editions and supplement records in the
same arrays. The first record is often a legacy record. Source order and an
array index do not establish the intended rules edition.

For ordinary revised-class source work, start with
[the 2024-only class view](../reference/2024/README.md). Its source index maps
records back to these unchanged originals and records their file hashes.

These are third-party reference/import inputs, not runtime game data or official
SRD verification. Keep them intact for provenance and existing importer paths.
Only inspect them directly when checking an original citation, edition difference
or source gap. Missing linked bodies stay missing until actually sourced.
