# Historical project material

These files preserve past evidence, plans and source observations. They do not
select current work or certify the current checkout. Start with the
[roadmap](../../roadmap.md), [current checkpoint](../operations/current.md) and
[documentation map](../README.md).

| Area | Contents |
|---|---|
| `gates/` | Old Gate 0-8 evidence, cohort checklist and historical defect register. |
| `reports/` | Dated playtests, import reviews, old changelog and artifact inventory. |
| `checkpoints/` | Superseded checkpoints retaining original acceptance receipts and limits. |
| `planning/` | Completed prompt queues and previous planning/status text. |

Current [ADRs](../decisions/README.md) remain in their existing home, including
superseded decisions whose still-binding constraints matter. Current mechanics,
source-gap inventories, production probes and test fixtures were not archived
merely because they have old dates. Reuse unchanged evidence when relevant;
do not rerun an old plan or reopen a closed defect without current evidence.
